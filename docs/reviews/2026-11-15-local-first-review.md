# Review: v2.0 local-first plan (D9)

Date: 2026-11-15. One independent reviewer subagent, covering backend, LLM, security, statistics and product, read the uncommitted v2.0 diff, `LEARNING_GUIDE.md`, the journal, and the probe and S3 code. Findings are ranked as the reviewer ranked them. Each has its resolution.

| ID | Finding | Resolution | Status |
|---|---|---|---|
| C1 | The transcribe schema was adopted against the only measurement (`gemma3:4b` 4/12, worse than months at 9/12), and the docs said "TBD" instead. Root cause: the schema required `year`, `month` and `months_ago` together, so the model filled two at once. The out files also came from three different probe versions, with no digest or Ollama version recorded. | The 4/12 is reported in the journal and the learning guide. The schema is now a one-of union with a `kind` field, plus an `unsupported` variant. All three models are re-run on one probe version that records digest, quantization, Ollama version, `remote_host` and the probe's own hash. Summaries are committed under `spikes/s2_local_llm/results/`, and the v1 outputs are kept in `out/v1/`. ARCH §5.1 no longer commits to transcribe: S2L decides between transcribe and months. | fixed |
| H1 | Ollama `*-cloud` models are served from localhost but proxied to ollama.com, which is paid and sends data off the machine. The base-URL guard can't see this. | `OllamaProvider` refuses any model whose `/api/show` reports `remote_host`, or whose tag ends in `-cloud`, and checks the pinned digest at startup (ARCH §2.7). Security group 8 tests this. The probe records `remote_host`. | fixed (design) |
| H2 | WSL2 NAT networking pushes users to `OLLAMA_HOST=0.0.0.0`, which exposes an unauthenticated API to the LAN, and makes the remote-URL override routine. | Mirrored networking is required. Ollama stays on 127.0.0.1. The NAT fallback binds only to the WSL interface, with a scoped firewall rule and an exact-IP allowlist. S1 checks that the worker can't reach Windows loopback and that Ollama isn't reachable from the LAN (ARCH §11, M1_SPIKES S1). | fixed (design; S1 verifies) |
| H3 | `num_ctx` was unmanaged. Ollama can silently truncate the front of a prompt, and the probe measured only ~300-token prompts. | One fixed `num_ctx` for all stages. A typed `context_overflow` failure before the call. S2L measures at realistic prompt sizes (ARCH §5.2, M1_SPIKES S2L). | fixed (design) |
| H4 | S2L gated PLAN only on validity, and a pruning PLAN could cost Full mode recall. "Identical numbers" across modes was false, because the BH families differed. | The playbook is confirmatory and always covers every confirmed dimension. PLAN orders dimensions and proposes extras but can't prune. BH runs as two families: confirmatory (identical in both modes, the only one that sets strength and outcome) and exploratory. The §5.5 wording is now precise (ARCH §5.1, §5.5, §6). | fixed |
| M1 | S2L statistics: 27/30 is weak evidence, metric substitution wasn't gated, the selection rule was undefined, retries were missing from the latency projection, and the criteria and questions weren't committed before the run. | Wilson CI reported. Zero substitutions required, with ≥ 8 unknown-metric cases. Selection is lexicographic. Retries are in the projection. Questions and criteria are committed with a hash before any call, and you're invited to co-write the questions. | fixed |
| M2 | The "last month" anchor was inconsistent (calendar vs. dataset), and there was no escape for unsupported periods. | Anchored to the dataset's latest complete month everywhere. `unsupported` variant added. | fixed |
| M3 | A ReAct baseline on a small model is a straw man. | The no-LLM baseline is now the headline comparison. ReAct runs on the strongest $0 configuration. Hand labels are blinded, and the re-run agreement metric is defined up front. | fixed |
| M4 | Showcase leakage, Pages being free only for public repos, and a meta-tag CSP that wasn't tested. | Allowlisted export schema plus a leak test. Repo confirmed public via the GitHub API. Group 13 tests the meta CSP. | fixed (design) |
| M5 | Leftover references: Anthropic wrapper, cost logs, v1.1/D1–D8 in CLAUDE.md, a missing review file, "Cost" in the metrics list, the stale RISKS tail, and a misleading VRAM table. | All corrected. This file now exists. | fixed |
